# DoD: Portfolio profesional moderno

## Listo cuando

- El PRD describe objetivo, público, UI y secciones
- El RFC define la arquitectura técnica y el modelo POO
- La UI tiene una dirección visual clara y consistente
- Existe hero, about, experience, skills, projects y contact
- Los proyectos pueden venir de GitHub o fallback local
- La navegación es fluida y responsive
- La tipografía, color y motion están alineados al concepto
- Los datos públicos reales del perfil están reflejados en la home

## Calidad mínima

- Mobile first
- Accesible por teclado
- Contraste suficiente
- CTA visible sin scroll profundo
- Sin animaciones gratuitas
- Sin componentes duplicados sin propósito

## Criterios técnicos

- Render rápido en Astro
- Separación clara entre dominio, aplicación e infraestructura
- Modelos de contenido representados con clases/entidades
- Integración de GitHub aislada detrás de un adaptador
- Repos pinned usados como selección inicial de proyectos

## Validación documental

- PRD, RFC y DoD viven en `docs/portfolio-website/`
- Los tres documentos están alineados entre sí
- No hay duplicación de scope con otros documentos
